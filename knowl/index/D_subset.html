Definition 6.1.1.

\(A\) is a subset of \(B\text{,}\) \(A\subseteq B\text{,}\) if for all \(x\text{,}\) if \(x\in A\) then \(x\in B\text{.}\)
🔗
\(A\) is a not a subset of \(B\text{,}\) \(A\nsubseteq B\text{,}\) if there exists \(x\text{,}\) such that \(x\in A\) and \(x\notin B\text{.}\)
